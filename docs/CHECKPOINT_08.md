# Checkpoint 08 — Visual polish and trust pass

This checkpoint responds to real-device feedback after the 1.0 production-candidate build.

## Changes

- Light mode is now the default regardless of the phone's system theme.
- Dark mode remains available as an explicit user choice under About > Appearance.
- The appearance choice is persisted locally.
- Calendar date tiles use stronger fill and border contrast in both light and dark modes.
- Card surfaces are more clearly separated from the page background.
- Android widget picker previews now use the real widget layouts instead of a generic app-icon placeholder.
- Widget preview layouts contain representative Hindi sample data; live widget data still replaces it after installation.
- Support/developer-contribution copy was rewritten to sound personal and natural rather than like a translated legal notice.
- The handwritten thank-you message was rewritten as a genuine personal gesture.
- Privacy wording was simplified while preserving the same data-handling commitments.
- Janmashtami/Holika explanatory text is rendered in more natural language on the Day page.
- Relative Panchang transition text now says `अगले दिन ... बजे तक` rather than the more ambiguous `कल ... तक`.
- Native launch stays light by default to match the app's default appearance.

No Panchang mathematics, Tithi/month calculation, festival-date selection rule, or personal-event matching rule was changed.
