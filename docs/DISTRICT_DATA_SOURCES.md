# District lookup data

Derived from geoBoundaries IND ADM2, boundaryID IND-ADM2-76128533, pinned commit 9469f09. Geometry rounded to 4 decimals (~11m). Sources: Pathways Data Pvt. Ltd., lgdirectory.gov.in. Boundary vintage 2021, source updated January 2023.

https://www.geoboundaries.org/api/current/gbOpen/IND/ADM2/
https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/9469f09/releaseData/gbOpen/IND/ADM2/geoBoundaries-IND-ADM2_simplified.geojson

Open Data Commons Open Database License 1.0: https://opendatacommons.org/licenses/odbl/1-0/
The derived database district_boundaries.json is distributed under ODbL 1.0 and included in the source package. This lookup is only a fallback for generic/division geocoder labels, not a current certified administrative map. Near borders or after district reorganizations, native district information takes precedence. No map is displayed.
