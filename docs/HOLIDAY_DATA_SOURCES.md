# Bundled state holiday reference data

2026 public and government categories from holidays 0.105, covering 28 states and 8 union territories. Restricted/optional holidays are excluded. Rajasthan and Delhi editorial entries retain their separately checked dates. This is a reference calendar, not a certification of leave entitlement; subsequent government orders and moon sightings can change dates. Some entries in the source library are estimates and remain labelled as such. Future state years are deliberately unavailable until updated.
