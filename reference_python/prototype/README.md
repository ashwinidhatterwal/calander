# Static UX Prototype — Checkpoint 02

Open `index.html` in a browser.

This prototype demonstrates the intended product hierarchy:

- Hindi by default with a full English toggle.
- Normal monthly calendar first.
- Gregorian date + Tithi + compact observance marker in each cell.
- Hindu month and today's summary on the main screen.
- Tapping a date opens a **separate Day Details page**.
- Day Details includes Tithi/Paksha/month, Nakshatra, Yoga, Karana, Sun/Moon timings, Rashi, useful Muhurta and caution periods.
- Festival/vrat cards are generated by the Checkpoint 02 festival engine rather than hard-coded prototype labels.
- Kshaya/Vriddhi Tithi warnings are supported by the data contract.

The generated demo dataset covers **30 August–15 November 2026** for Sri Ganganagar so it includes representative major festivals in the prototype data.

Regenerate with:

```bash
python tools/generate_demo.py
```

This is still a browser prototype for interaction and information hierarchy. Checkpoint 03 will replace it with the real Flutter mobile UI.
